# Course Exemption Approval Portal – Backend

This repository contains the **backend code** for the Course Exemption Approval Portal, designed to streamline the approval process for online and one-credit courses within an educational institution.

## Features
✅ **User Authentication** – Secure login using **JWT authentication**.  
✅ **Role-Based Access** – Separate dashboards for **students, faculty, and admins**.  
✅ **Application Management** – Students can **submit course exemption requests**.  
✅ **Approval Workflow** – Faculty can **review and approve/reject applications** sequentially.  
✅ **Reports & Filters** – Admins can filter applications based on **name, year, semester, department, and status**.  
✅ **API Security** – Middleware protection ensures **authorized access to endpoints**.  

## Tech Stack
- **Node.js** – Backend runtime  
- **Express.js** – Web framework  
- **MySQL** – Database 
- **JWT** – Secure authentication  
- **Middleware** – API protection and role-based access control
